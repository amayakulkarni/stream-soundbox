Ambience sounds. A file named after the room plays there on a loop, for example `the-lounge.mp3`, or put several in a folder `the-lounge/` for a random one each time. Your files win over `generated/`.
Rooms: the-lounge, build-room, backstage, core-room, elder-campfire, elder-lounge, art-studio, writing-desk.
`npm run ambience:generate` makes a soft synth loop for each room in `generated/`. Only add music you have the rights to play.
