# 🛠️ Maker Workbench
The technical hub. Show what you've made, ask how something works, or get a second pair of eyes on a stuck project.

**On the bench**
🖨️ 3D printing: lithophanes, functional parts, print settings and failed-print autopsies
📐 Parametric CAD: models, constraints, tolerances
🟩 Node.js and backend: APIs, bots, bridges, headless commerce
🌐 Homelab and networking: OpenWrt, VLANs, zero trust, routing setups
⚡ Electronics: microcontrollers, sensors, wiring

**Asking for help? Include:**
• What you expected and what happened
• Error messages as text in a code block, not a photo of your screen
• Printer and slicer, or OS and versions

**Before you post a screenshot**: hide IP addresses, MAC addresses, API keys, tokens and passwords. Never paste a secret, even an expired one.
